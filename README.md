# Python Patterns Assignment

## Overview

This repository contains 25 Python pattern programs implemented using functions and loops. The notebook demonstrates various star patterns, number patterns, hollow patterns, and mathematical patterns.

## Topics Covered

### Star Patterns

- Square Hollow Pattern
- Diamond Pattern
- Butterfly Pattern
- Rhombus Pattern
- K Pattern
- Triangle Pattern
- Hollow Diamond
- Hollow Hourglass

### Number Patterns

- Number Triangle
- Increasing Pyramid
- Reverse Pyramid
- Changing Pyramid
- Reverse Number Triangle
- Mirror Image Triangle

### Special Patterns

- Zero\-One Triangle
- Palindrome Triangle
- Pascal's Triangle
- Right Pascal's Triangle

## Technologies Used

- Python 3
- Jupyter Notebook

## Learning Outcomes

- Nested loops
- Conditional statements
- Pattern generation logic
- Mathematical computations
- Function\-based programming
